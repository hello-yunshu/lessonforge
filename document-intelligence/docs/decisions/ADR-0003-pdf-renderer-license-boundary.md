# ADR-0003：PDF解析与渲染器必须保持可替换并设置许可证门禁

- 状态：Accepted
- 日期：2026-08-02

## 背景

Phase 1/2的Native PDF解析、页面渲染和标准页面生成使用PyMuPDF。当前安装包元数据声明为AGPL-3.0或Artifex商业许可证双重许可。该依赖的许可证选择会直接影响平台的发行与部署方式。

## 决策

1. 将PyMuPDF标记为生产发行阻断依赖；
2. 在未完成许可证审查前，不把当前构建描述为可直接闭源商业发行；
3. Parser SDK、标准库和匹配协议不得暴露PyMuPDF专有对象；
4. 后续阶段增加PDF渲染器协议，使Native PDF文本提取与页面渲染可以独立替换；
5. 替换实现必须通过Schema、语义摘要、页面匹配、资源限制和黄金集回归；
6. 许可证结论与技术资格结论分别记录，不互相替代。

## 结果

- 当前0.2.0仍可用于研发、评测和架构推进；
- 正式生产发行必须满足AGPL兼容、商业授权或完成替换三者之一；
- 后续不得用“开源依赖”笼统代替逐项许可证审查。

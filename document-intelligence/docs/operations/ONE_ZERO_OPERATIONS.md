# 1.0运行与发布规范

## 启动前

1. 执行 `doc-intelligence freeze-verify`；
2. 执行Phase 1—9全部验证脚本；
3. 确认所有写入开关默认关闭；
4. 确认运行目录不含发行包自带状态；
5. 按部署用途完成PyMuPDF许可证审查；
6. 生产外部解析器必须固定服务、模型和容器摘要。

## 冻结失败

`freeze-verify`出现任何差异时：

- 不得发布1.x包；
- 不得重新生成v1清单掩盖差异；
- 判断是内部实现偏移、可隔离新增能力，还是需要2.0迁移；
- 修复后重新执行完整门禁。

## 回滚

- 应用发行包按完整ZIP或wheel版本回滚；
- 模型通过Champion/Rollback别名原子回滚；
- Rill Assist通过撤销激活回滚；
- 解析器熔断通过受控恢复记录回滚；
- 任何回滚均保留原不可变审计记录。

## 禁止事项

- 修改或删除冻结清单后仍使用1.x版本号；
- 将合成基准作为生产准确率；
- 在发行包中附带生产状态、私钥或令牌；
- 启用boundedAuto；
- 让Domain Pack执行Python、Shell或任意动态代码。

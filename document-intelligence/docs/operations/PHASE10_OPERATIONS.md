# Phase 10 运维与生产资格操作规范

## 1. 默认状态

生产资格写入默认关闭，访问令牌默认未配置。空工作区应显示：

- `qualifiedReportCount = 0`；
- `automaticReleaseAuthorized = false`；
- `boundedAuto = false`。

## 2. 证据采集顺序

1. 冻结真实黄金集与挑战集；
2. 固定外部解析器运行时、模型、镜像和配置摘要；
3. 在保护集上完成确定性资格测试；
4. 完成168小时Soak、并发和恢复演练；
5. 从正式CI导入Ruff、Mypy、测试、SBOM、漏洞、许可证、镜像和签名证据；
6. 完成PyMuPDF许可或替换决策；
7. 完成真实小规模试运行和回滚演练；
8. 生成综合资格报告；
9. 由独立人员复核报告和原始证据后决定发布。

## 3. 禁止事项

- 不得把合成基准登记为`origin=real`；
- 不得让黄金集或挑战集进入训练血缘；
- 不得使用浮动容器标签替代镜像摘要；
- 不得使用模型名称替代模型文件SHA-256；
- 不得将本地静态检查替代正式Ruff/Mypy CI；
- 不得在许可证未解决时把PyMuPDF路线标记为通过；
- 不得把资格报告当作自动发布授权。

## 4. 备份与恢复

`var/production-qualification`必须纳入不可变备份。恢复后应逐条调用读取接口触发摘要复核。
损坏记录不得修补覆盖，应从原始证据重新生成新的记录。

## 5. 策略变更

策略调整会改变`policy_sha256`和资格报告ID。旧报告保留审计，但不能证明当前策略下仍然合格。

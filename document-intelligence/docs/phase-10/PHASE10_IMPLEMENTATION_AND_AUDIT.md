# Phase 10：生产资格与真实验证框架实施、自审与冻结报告

## 1. 阶段结论

`document-intelligence 1.0.1` 已完成生产资格证据系统。该系统用于证明或阻断生产资格，
不把合成测试、工程测试或单次演示冒充为生产证据。

本发行包没有内置真实黄金集、固定外部解析器产物、168小时Soak、正式Ruff/Mypy CI、
PyMuPDF许可证明或真实试运行记录，因此当前生产资格仍为 **blocked**。

## 2. 实现范围

新增 `document_intelligence.production`：

- `DatasetQualificationEvidence`：真实黄金集与挑战集证据；
- `ParserQualificationEvidence`：解析器版本、运行时、模型、镜像、配置摘要与真实指标；
- `ScaleQualificationEvidence`：规模、并发、Soak、幂等、重启、磁盘满、损坏检测与索引重建；
- `SupplyChainQualificationEvidence`：Ruff、Mypy、测试、覆盖率、SBOM、漏洞、许可证、镜像、可复现构建与发布签名；
- `LicenseQualificationEvidence`：组件发行许可或替换决策；
- `PilotQualificationEvidence`：真实小规模试运行、专家复核、P0/P1、人工修改和回滚演练；
- `ProductionQualificationReport`：综合门禁报告。

所有记录均采用不可变目录、记录摘要、语义摘要、安全ID、原子提交和读取时复核。

## 3. 资格硬门禁

默认策略要求：

- 黄金集与挑战集均来自真实数据；
- 至少覆盖3个领域；
- 黄金集不少于100份文档，挑战集不少于50份；
- 黄金集与挑战集内容摘要不同；
- 至少一个外部解析器固定运行时、模型、容器镜像和配置摘要；
- 解析器整体及各领域准确率不低于0.90；
- P0、P1和严重错误为零；
- 重放确定率为1.0；
- Soak不少于168小时，并发不少于8，文档不少于10000；
- 重启、幂等、磁盘满、损坏检测和索引重建全部通过；
- Ruff、Mypy、测试、SBOM、漏洞扫描、许可证扫描、可复现构建和发行签名全部有证据；
- 关键及高危漏洞为零；
- PyMuPDF必须有商业许可、兼容开源发行证明，或已被替换；
- 真实试运行不少于7天、500份文档、100份专家复核；
- 试运行P0、P1、严重错误和未关闭高严重度事件为零；
- 回滚演练通过。

阈值可以在批准环境中调整，但最终报告会使用**当前策略重新计算**，不会永久相信旧策略下的`passed`。

## 4. 安全边界

- `DI_ENABLE_PRODUCTION_QUALIFICATION_WRITES=false`为默认值；
- 访问使用独立令牌摘要；
- 资格报告不能自动发布；
- `automatic_release_authorized=false`固定；
- `human_release_required=true`固定；
- `bounded_auto=false`固定；
- 资格系统不执行训练、解析器安装、Shell、模型切换或Rill动作；
- 现有1.0冻结清单未修改，`FreezeService().verify()`继续完全兼容。

## 5. 实施后自审与修复

1. **旧策略结论复用风险**：最终报告原先可能只读取登记时的`passed`。现使用当前策略重新检查数据规模、领域数、解析器指标、Soak、覆盖率和试运行阈值。
2. **保护集泄漏**：黄金集与挑战集必须有不同内容摘要，挑战领域必须被黄金集覆盖。
3. **解析器血缘缺口**：解析器证据引用的黄金和挑战记录必须同时出现在最终资格请求中。
4. **源代码不一致**：规模证据与供应链证据必须绑定同一源提交。
5. **许可证冲突**：同一组件存在多份许可证证据时阻断，避免选择性取用。
6. **不可变记录冲突**：同一稳定ID不同内容拒绝覆盖。
7. **篡改检测**：记录文件、模型类型和语义摘要任一不一致均拒绝读取。
8. **锁永久阻塞**：加入遗留锁超时清理；并发提交仍保持原子。
9. **短写风险**：文件写入循环直到完整写入并执行`fsync`。
10. **发行态污染**：发布包排除`var/production-qualification`中的所有运行记录。
11. **1.x兼容门禁**：Phase 9旧验证由“必须等于1.0.0”修正为冻结的`>=1.0.0,<2.0.0`。
12. **领域指标旧阈值复用**：最终报告现在依据当前策略逐领域重算解析器准确率，并验证领域指标与黄金集领域集合完全一致。

## 6. 验证结果

- Phase 1—9兼容验证通过；
- Phase 10确定性资格基准10/10通过；
- 216项自动测试全部通过；
- 精确综合覆盖率80.40%；
- 1.0冻结清单实时兼容；
- wheel任意目录导入、安装后CLI和生产资格模块导入通过；
- 发布包不包含任何生产资格记录；
- 源码哈希清单包含464项；
- 完整ZIP包含465个文件；
- 独立解压后重新验证通过。

## 7. 冻结判断

- 生产资格框架：通过；
- 生产资格证据不可变性：通过；
- 1.x冻结兼容性：通过；
- 当前发行包生产资格：不通过；
- 自动发布：未开放；
- boundedAuto：继续硬禁用。

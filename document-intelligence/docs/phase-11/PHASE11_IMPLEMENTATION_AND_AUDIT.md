# Phase 11 实施、冻结与自审报告

## 1. 阶段结论

Phase 11 将生产资格从“零散提交证据”推进为可恢复、可审计的执行活动：

> 生产资格活动编排与试运行运维。

项目版本升级为 `1.0.2`。本阶段保持1.x冻结契约兼容，不修改既有Schema语义，
不执行训练、解析或Shell脚本，不生成真实证据，不自动发布，也不启用`boundedAuto`。

## 2. 新增能力

- 不可变活动Manifest与有向无环步骤图；
- 外部数据授权后才能启动；
- 有期限Worker租约、心跳、过期回收和并发互斥；
- 可恢复检查点、游标摘要和有限指标；
- 生产资格证据类型、角色、源码提交和环境摘要交叉校验；
- 连续、不可变、带前序摘要的事件哈希链；
- 暂停、恢复、失败、重试和取消状态机；
- 只有全部依赖完成后才允许综合资格评估；
- 资格报告仍固定要求人工发布，自动发布始终关闭；
- 确定性密封ZIP，可验证、可幂等恢复；
- 密封包不包含原始文档，只包含活动记录和引用的资格证据；
- API、CLI、Schema、Docker配置和发行验证。

## 3. 安全边界

### 3.1 默认拒绝

以下设置默认关闭或为空：

```text
DI_ENABLE_QUALIFICATION_CAMPAIGN_WRITES=false
DI_QUALIFICATION_CAMPAIGN_ACCESS_TOKEN_SHA256=
```

读取和写入接口都需要活动访问令牌；恢复密封包还同时需要生产资格写权限和
生产资格访问令牌，因为恢复会写入生产资格证据命名空间。

### 3.2 不执行任意代码

活动步骤仅记录外部验证工作的状态和证据引用。核心系统不会：

- 执行步骤中的命令；
- 运行训练或解析脚本；
- 下载模型；
- 生成或篡改现实证据；
- 自动切换模型、解析器或发布别名。

### 3.3 不自动发布

所有活动快照和密封包固定包含：

```text
automatic_release_authorized=false
bounded_auto=false
```

即使综合资格报告为`qualified=true`，仍只代表证据满足当前策略，发布必须由独立人工流程完成。

## 4. 不可变存储

活动存储位于`var/qualification-campaigns`，包括：

- Manifest及独立SHA-256；
- 逐事件目录、记录摘要和链摘要；
- 可过期控制锁；
- 受控导出目录。

读取时重新验证文件摘要、事件序号、前序链、活动ID和最终链摘要。发现缺失、篡改、
序号中断或符号链接替换时失败关闭。

## 5. 密封包

密封包固定时间戳并按路径排序生成，内容包括：

- 活动Manifest；
- 完整事件链；
- 被活动引用的生产资格证据；
- Bundle Manifest及每个成员SHA-256。

导入前检查：

- 路径穿越、绝对路径和反斜杠；
- 重复成员和非法目录；
- 声明大小、成员数、解压总量和压缩比；
- Manifest摘要和每个文件摘要；
- 活动Manifest、事件链和生产证据语义一致性。

重复导入相同包是幂等操作；同ID不同内容失败关闭。

## 6. 实施后自审与修复

自审发现并修复：

1. 重复导入同一备份最初不幂等；
2. ZIP成员在读取前缺少声明尺寸和压缩比校验；
3. Bundle生成时间可能导致同一内容身份不稳定；
4. 综合资格步骤可能被普通Worker租约领取；
5. 同一证据可被同一步骤重复链接；
6. 备份恢复最初只要求活动写权限，没有同时要求生产资格写权限；
7. 历史包中的旧策略合格报告可能被误当成当前策略资格；
8. API导出曾暴露服务器绝对路径；
9. 检查点指标未充分限制非有限值；
10. 活动存储命名空间在初始化后可能被符号链接替换；
11. 事件链读取需要区分记录不存在与记录损坏；
12. 基准脚本最初错误依赖测试模块，独立分发环境无法运行；
13. Schema导出遗漏`CampaignEvent`公共导出；
14. Compose中的默认租约值曾与应用默认值不一致。

## 7. 验证结果

- 自动测试：232项通过；
- 精确综合覆盖率：80.21%；
- Phase 11确定性基准：10/10通过；
- 1.x冻结验证：通过；
- API默认拒绝和双权限恢复：通过；
- 静态安全、wheel分发和独立导入：通过；
- `boundedAuto`：硬关闭；
- 发行包内活动运行记录：0。

最终发行打包后将从全新目录独立复核489项源码摘要、232项测试和Phase 9—11门禁。确定性基准只验证编排语义，不能替代真实
168小时持续运行、真实数据集、正式外部解析器或真实试运行证据。

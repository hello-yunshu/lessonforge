# Phase 3 通用结构恢复实施与自审

## 1. 阶段目标

在不引入任何单一领域语义的前提下，为已解析文档恢复：

- 阅读顺序；
- 标题层级；
- 内容分组；
- 图文关联；
- 跨页连续关系；
- 重复页眉页脚识别；
- 整文档一致性和证据链。

## 2. 已完成实现

### 2.1 Structure Result独立协议

新增 `StructureResult`，不覆盖原始解析结果。结构结果记录：

- 来源文档、来源解析运行和来源语义摘要；
- 引擎版本、引擎摘要和配置摘要；
- 完整阅读顺序和正文阅读顺序；
- 被排除的重复边缘元素；
- 标题大纲、内容组、关系、证据和诊断；
- 完整性指标及确定性语义摘要。

结构Schema版本为1.0，核心解析Schema仍保持1.1，避免为结构扩展破坏已有解析合约。

### 2.2 阅读顺序

- 全宽元素作为垂直分隔锚点；
- 分段后根据水平中心间隙识别最多四栏；
- 栏内自上而下、栏间自左向右；
- 少量并排元素通过强水平间隔和垂直重叠恢复左到右顺序；
- 所有元素必须且只能出现一次，否则结构恢复失败。

### 2.3 标题层级

- 只使用解析器已经标记为通用Heading的元素；
- 根据归一化高度聚类推断1—6级标题；
- 限制层级跳跃；
- 使用前序栈建立父子关系；
- 每个大纲节点保存标题证据和作用范围。

### 2.4 内容分组和图文关联

- 邻近、同页、同列的文本形成通用文本组；
- 图片、图形、表格和公式可与图注形成组；
- 图注关系必须满足距离、水平重叠、长度和位置门禁；
- 无显式图注前缀时，额外要求紧邻、居中和宽度收缩；
- 每个组和每条关系都必须引用规则推断证据。

### 2.5 跨页关系

- 只检查相邻页面边界处的文本、列表或表格；
- 候选沿已经恢复的正文阅读顺序选择；
- 文本要求页尾/页首位置、水平对齐和非终止语义信号；
- 表格要求页尾/页首位置；
- 未达到保守阈值时不产生关系，并输出信息级诊断。

### 2.6 重复边缘元素

- 识别多页重复的顶部或底部文本；
- 数字页码在底部时可直接排除；
- 数字归一化后比较，避免不同页码无法聚类；
- 完整阅读顺序仍保留这些元素，正文阅读顺序明确排除。

### 2.7 持久化与来源绑定

新增 `var/structures/` 独立命名空间：

```text
var/structures/<structure_id>/
├── manifest.json
└── result.json
```

读取时验证：

- 结果文件SHA-256；
- 结构语义摘要；
- 文档ID和解析运行ID；
- 来源语义摘要；
- 引擎和配置摘要；
- 来源解析运行仍存在且完整。

结构结果不能在来源运行缺失或变化时单独作为可信事实返回。

## 3. API和CLI

新增：

- `POST /v1/structure/recover`；
- `GET /v1/structures/{structure_id}`；
- `doc-intelligence structure-recover`；
- `doc-intelligence structure-get`。

路径参数和请求标识继续采用安全ID约束。

## 4. Rill适配

Rill Observe Schema升级到0.3，新增：

- 阅读顺序覆盖率；
- 关系证据覆盖率；
- 一致性分数；
- 大纲节点、内容组、关系和跨页关系数量；
- 结构诊断数量。

`shadow_only`仍为常量true。本阶段不提前开放Rill Assist、阈值自动修改或任何生产动作。

## 5. 实施后自审发现并修复的问题

| 级别 | 问题 | 修复 |
|---|---|---|
| P1 | Phase 2 CLI测试写死旧绝对配置路径，ZIP换目录后失败 | 改为使用包内默认配置，增加验证门禁 |
| P0 | 结构结果可在来源解析运行丢失后独立返回 | StructureService读取时反向校验来源运行和语义摘要 |
| P1 | 跨页候选重新按几何顺序选择，可能偏离多栏阅读顺序 | 沿恢复后的正文阅读顺序选择页首页尾候选 |
| P1 | 无前缀短正文紧邻图片时可能被误判为图注 | 增加紧邻、居中、宽度和长度联合门禁 |
| P1 | 两三个并排块因样本不足退化为纵向排序 | 增加稀疏并排布局检测 |
| P1 | 引擎摘要只绑定算法文件，没有绑定结果模型实现 | 引擎摘要同时绑定engine.py与models.py |

## 6. 测试和门禁

当前完成：

- 82项自动测试全部通过；
- 总分支覆盖率高于80%；
- Phase 1、Phase 2和Phase 3验证脚本通过；
- 结构合成回归8/8通过；
- 负例错误关系为0；
- 关系证据覆盖率100%；
- 结构结果确定性和存储篡改测试通过；
- 来源解析运行缺失时拒绝返回结构结果；
- 核心代码领域中立检查通过；
- wheel独立安装和任意工作目录导入纳入发布门禁。

## 7. 当前限制

1. 真实复杂文档黄金集尚未建立；
2. 标题层级主要依赖通用Heading类别和几何高度，尚未使用字体元数据；
3. 三栏以上、浮动侧注、复杂脚注和嵌套列表仍需真实样本验证；
4. 跨页关系是保守启发式，不是语义模型；
5. PaddleOCR、OpenDoc和MinerU仍未完成固定模型资格测试；
6. PyMuPDF许可仍阻断不兼容AGPL的闭源生产发行；
7. Ruff和Mypy未能在本地安装，不宣称本地通过；
8. Rill继续保持Shadow。

## 8. 阶段结论

Phase 3工程实现和本地确定性门禁通过，可以作为Phase 4 Domain Pack Runtime的开发基线。生产资格仍为有条件通过，不能扩大为真实行业结构准确率声明。

# Phase 3 通用结构恢复基准

## 1. 目的

本基准用于验证结构恢复引擎的确定性和最低工程门禁，不用于宣称真实行业文档准确率。

## 2. 覆盖场景

- 单页双栏阅读顺序；
- 标题层级和父子关系；
- 图片与显式图注关联；
- 邻近但不满足图注几何条件的正文拒绝关联；
- 跨页正文连续关系；
- 以终止标点结束的页面拒绝强制跨页连接；
- 重复页眉和页码过滤；
- 同一输入的结构ID与语义摘要确定性。

## 3. 当前结果

以 `docs/phase-3/benchmark_results.json` 为事实来源：

- 8/8场景通过；
- 双栏阅读顺序精确匹配率：100%；
- 合成关系Precision：100%；
- 合成关系Recall：100%；
- 负例错误关系：0；
- 关系证据覆盖率：100%。

## 4. 解释边界

上述数据只覆盖人为构造、目标明确的小型回归场景。它不能替代：

- 真实扫描文档；
- 三栏及复杂不规则布局；
- 大量浮动图、侧注和脚注；
- 多页表格和列表；
- 不同语言阅读方向；
- 真实出版社、合同、论文、报告等领域黄金集。

因此，0.3.0只能判定为Phase 3工程基线通过，不能判定为生产准确率冻结。

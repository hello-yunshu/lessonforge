# Phase 4 Domain Pack Runtime 基准报告

## 范围

本报告是确定性、合成式工程回归，不是对任意真实行业文档的准确率声明。输入使用项目内固定
文档、结构和 `education-content` 验证包，用于验证运行时契约、证据、失败隔离和审核闭环。

## 基准项目

1. 同一输入与同一包重复执行得到相同领域结果 ID 和语义摘要；
2. 声明式对象规则识别预期验证对象；
3. 声明式关系规则恢复预期验证关系；
4. 领域结果落盘后通过完整性回读；
5. 通用解析结果和通用结构摘要保持不变；
6. 适配异常只生成无领域断言的通用回退结果；
7. 审核导出重复调用幂等；
8. 审核回传可完整读取并绑定来源摘要。

## 结果

机器可读结果位于 `benchmark_results.json`。冻结运行要求 8/8 全部通过、领域对象证据覆盖率
为 1.0、回退领域断言数量为 0。

## 不包含的结论

- 不代表教育内容或其他领域的真实分类准确率；
- 不代表复杂跨页、低质量扫描或多语言文档的生产表现；
- 不代表第三方 LabelU 前端的完整兼容认证；
- 不代表大规模并发安装或百万级领域结果索引能力。
